Research note · Zero-shot topic classification · Sep 2026

LLMs vs Embeddings

Topic classification is usually handed to a frontier LLM with a zero-shot prompt. An embedding model is a far cheaper alternative: embed the document and each label, and pick the label closest to the document. This experiment asks whether that nearest-label classifier matches two frontier LLMs in accuracy, and what it saves in cost and latency.

  • Three candidates, one test set. gpt-6-sol, gemini-3.1-pro-preview and gemini-embedding-2 classify the same 1,528 Usenet posts.
  • No training data. Every candidate sees only the label names and a one-line description of each, so the comparison is about the method, not a trained classifier.
  • The embedding is 10× cheaper per input token at list price, and it produces no output tokens at all.

Research questions

What each run of the experiment answers.

  1. Accuracy

    Does the zero-shot embedding classifier reach accuracy and macro-F1 comparable to zero-shot prompted LLMs on the same test set?

  2. Cost

    What does each method cost per document, at list price?

  3. Latency

    How long does each method take to return a label for one document?

Method

Each post goes to every candidate in turn. None of them uses labelled training data.

Embedding Embedgemini-embedding-2Post and label descriptions embedded with the classification prefix; the closest label by cosine similarity wins

How an LLM chooses

Generates
  1. Read an instruction, the four labels with their descriptions, and the post.
  2. Reason about the topic.
  3. Reply with one label. A JSON schema limits the reply to the four label names, so it can't answer anything else; it can only refuse.

How the embedding chooses

Compares
  1. Turn the post into a vector: similar meanings point in similar directions.
  2. Turn each label description into a vector, once per run.
  3. Score each label by cosine similarity to the post and pick the highest. It always returns a label and never refuses.

Headers, signatures and quoted replies are stripped from every post. Headers contain a Newsgroups: line that states the label outright, and signatures and quotes let a classifier match on the author or thread instead of the topic. Every candidate sees the same descriptions, written from each newsgroup's charter before any results were seen.

Macro-F1 averages the F1 score of each class equally, so a method that collapses one class scores low even when overall accuracy looks fine. A paired bootstrap on each LLM's macro-F1 minus the embedding's shows whether the gap is real: if its interval contains 0, the two can't be told apart on this data.

Limitations

  • Nearest-label classification depends on how well the label text describes each class. Terse or ambiguous labels hurt the embedding most, which is why every candidate gets the same descriptions.
  • The LLMs' output is constrained to the four labels, which is a different condition from free-text zero-shot prompting.
  • Latency is measured over the public internet and carries network variance.
  • List prices change; cost figures hold only at the time of the run.
  • The confidence intervals cover which posts were sampled, not LLM randomness between reruns or the choice of prompt.
