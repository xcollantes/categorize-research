Classification with LLMs vs Embedding Models

Xavier Collantes · Source

Summary

Topic classification is commonly delegated to frontier LLMs through zero-shot prompting. An embedding model offers a cheaper alternative: the document and each candidate label are embedded, and the label with the highest cosine similarity to the document is assigned. This experiment asks whether the embedding approach matches a prompted LLM in accuracy, and at what difference in cost and latency. Neither method uses labelled training data.

Research questions

  1. Does a zero-shot embedding classifier match a zero-shot prompted LLM in accuracy and macro-F1?
  2. What does each method cost, and how long does it take, per document?
  3. Does the classification task prefix recommended for gemini-embedding-2 measurably improve accuracy?

Method

ConditionModelProcedure
LLM OpenAI model (Responses API) Zero-shot prompt listing the candidate labels
Embedding gemini-embedding-2 Nearest label by cosine similarity

Both conditions are scored on the same test set: 20 Newsgroups, four classes (comp.graphics, rec.sport.baseball, sci.space, sci.electronics), headers, footers and quotes stripped, seed 67. Reported metrics are accuracy and macro-F1 with 95% bootstrap confidence intervals, cost per document, and latency per document.
